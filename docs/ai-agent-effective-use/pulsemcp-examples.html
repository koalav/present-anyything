PulseMCP에서 볼 수 있는 예시

확인일: 2026-05-13. PulseMCP는 MCP 서버, MCP 클라이언트, 실제 유스케이스를 모아 보는 디렉터리입니다. 발표 중에는 아래 링크를 열어 “MCP가 실제로 어떤 업무 도구와 연결되는가”를 보여주면 됩니다.

서버 예시

타입 예시 발표에서 연결할 메시지
브라우저 / 디버깅 Playwright, Chrome DevTools 웹뷰, 콘솔, 네트워크, 성능을 실제 브라우저로 확인한다.
코드 / 저장소 Git, Filesystem, GitHub, GitLab 답변이 아니라 파일 수정, diff, PR까지 작업 루프에 넣는다.
문서 / 검색 Context7, Fetch, AWS Documentation, searchcode 모델 기억 대신 최신 문서와 코드 인덱스를 컨텍스트로 넣는다.
업무 시스템 Jira, Confluence, Notion, Slack 요구사항, 이슈, 결정 사항을 에이전트 작업 입력으로 연결한다.
데이터 / 분석 PostgreSQL, DuckDB, SQL, Supabase, MongoDB 가설을 데이터 조회와 검증 가능한 증거로 닫는다.
자동화 / 제작 Figma, Storybook, n8n, Excel, PowerPoint 디자인, UI 테스트, 문서 생성 같은 반복 작업을 도구화한다.

클라이언트 예시

타입 예시 역할
IDE / 에디터 VS Code, Zed, Continue, Cline 계열 개발 중인 코드베이스와 MCP 서버를 같은 작업 흐름에 둔다.
터미널 코딩 에이전트 Gemini CLI, OpenCode, Goose 셸 실행, 파일 수정, 테스트 루프를 중심으로 작업한다.
데스크톱 챗 Claude Desktop, Cherry Studio, LibreChat 일반 대화형 UI에서 외부 도구와 데이터를 호출한다.
프레임워크 / 디버깅 mcp-agent, fast-agent, MCP Inspector 직접 에이전트나 MCP 서버를 만들고 테스트한다.

유스케이스 예시

사례 Client 말하고 싶은 포인트
코딩 중 웹 검색 붙이기 Cursor IDE 최신 문서를 찾아 코드 설계 중 바로 반영한다.
GitHub 저장소 코드 변경과 PR Goose 질문 답변이 아니라 repository action까지 연결된다.
코드베이스를 지식 그래프로 만들기 Cline 대형 repo에서 컨텍스트 선택과 구조 이해를 보강한다.
Figma를 HTML/CSS로 변환 Claude Desktop 디자인 도구를 컨텍스트와 실행 도구로 연결한다.
Supabase schema 동기화 Windsurf IDE DB 상태를 IDE 작업과 맞춰 hallucination을 줄인다.
Stripe invoice 발행 Claude Desktop 외부 API 호출은 편리하지만 승인, 권한, 로그가 필요하다.
