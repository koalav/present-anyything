Variant 01

Manual vs
Tool-Calling Work

Same security question, different execution path

Without Tool Calling

Answer-only AI response, followed by human-led code review.

  • 1Generic vulnerability list from the model
  • 2Manual search across source, manifest, and dependencies
  • 3Higher effort, slower review, missing-evidence risk

With Tool Calling

Target artifact plus request, then controlled tool execution.

  • 1APK or repository as concrete target input
  • 2File analysis, code search, web search, dependency analysis
  • 3Evidence-backed summary with impact, reproduction, and caveats
