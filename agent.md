# Presentation Agent Rules

## Slide Structure

- Each slide must contain a title, one core message, and a body area with content or a diagram.
- Prefer tables, structures, process flows, and comparison tables over simple bullet lists.
- Do not place excessive text on one slide.
- Keep all slide text editable in PowerPoint whenever a PPTX is generated.
- Generate tables and simple charts as native PowerPoint objects whenever possible.
- After generation, render and review the deck for text clipping, overlap, alignment, spacing, and font issues. Fix any issues found.

## Visual Style

- Use a corporate report presentation style suitable for large or mid-sized companies.
- Use 16:9 wide layout.
- Use a light theme with white or pale gray backgrounds.
- Use navy, gray, and light blue as primary colors.
- Avoid excessive decoration, character-like visuals, and startup pitch-deck styling.
- Use restrained boxes, tables, process diagrams, and comparison tables.

## Writing Style

- Use formal Korean report style.
- Prefer noun-ending labels and section titles.
- Examples: "추진 배경", "주요 이슈", "개선 필요성", "추진 방안", "기대 효과", "향후 계획".
- Avoid emotional or advertising-style copy.
- Do not invent numbers or facts that are not present in the source. Mark them as "가정" or "추가 확인 필요" when needed.

## Project Application

- HTML decks may be used for preview, but PPTX export should prefer editable PowerPoint text, shapes, tables, and diagrams.
- Screenshot-based PPTX export may be used only as a fallback for decks without a native export definition.
- Source markdown and generated HTML must remain aligned when deck content changes.
